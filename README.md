# HTML5 Forms Demo

## Overview
This project demonstrates the use of various HTML5 form input types. The form collects basic organizational information such as name, email, office details, contact number, website URL, and includes a submit image button.

## Features
The form includes the following HTML5 input fields:

- Text Input (Name)
- Email Input (E-mail)
- Date Picker (Date of Inception)
- Time Picker (Office Time)
- Number Input (Years Completed)
- Telephone Input with Pattern Validation
- URL Input (Homepage)
- Image Submit Button

## Technologies Used

- HTML5
